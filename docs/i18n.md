## i18n (Translations) — LenaAI Website

- Locales live in `public/locales/en.js` and `public/locales/ar.js` as JS objects.
- `I18nProvider` (`src/context/translate-api.js`) reads the `lang` cookie on mount, sets `locale`, and exposes `{ locale, t, changeLanguage }`.
- `t` is the full locale object for the active language (`ar` or `en`).
- Use `useI18n()` (`src/hooks/useI18n.js`) in client components to access `locale` and translation helpers.
- Prefer `translate('some.nested.key')` for UI strings; it safely reads from `t` via `safePropertyAccess`.
- During development, use `translateStrict('key.path')` to fail fast if a key is missing (prevents showing raw keys in UI).
- `changeLanguage('ar'|'en')` persists to cookie and keeps `<html lang>` / `<html dir>` in sync (`rtl` for Arabic, `ltr` for English).
